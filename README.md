# 🚁 PickmeDrone: Simulation & Development Environment

Среда разработки и симуляции автономного квадрокоптера на базе **PX4-Autopilot (SITL)**, **Gazebo Harmonic** и **ROS 2 Humble**.

---

## 🏛 Архитектура системы

Система разделена на три изолированных Docker-контейнера и локальный 3D GUI:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        macOS Host (OrbStack)                           │
│                                                                        │
│   ┌──────────────────────────────┐                                     │
│   │   Gazebo 3D GUI (Нативно)    │ ◄─── (gz sim -g через GZ_RELAY)     │
│   │   Загружает 3D-меши с диска  │                                     │
│   └──────────────▲───────────────┘                                     │
│                  │                                                     │
│   ┌──────────────┴─────────────────────────────────────────────────┐   │
│   │                   Docker Network (`ros_net`)                   │   │
│   │                                                                │   │
│   │  ┌───────────────────────┐         ┌────────────────────────┐  │   │
│   │  │       px4-sim         │         │     ros-sim-bridge     │  │   │
│   │  │ ───────────────────── │ gz-pipe │ ────────────────────── │  │   │
│   │  │ • Gazebo Server (-s)  │────────►│ • ros_gz_bridge        │  │   │
│   │  │ • PX4 SITL (x500)     │         │   (Clock, Sensors)     │  │   │
│   │  │ • Micro-XRCE-DDS      │         └───────────┬────────────┘  │   │
│   │  └───────────┬───────────┘                     │ ROS 2         │   │
│   │              │ XRCE-DDS (port 8888)            │ Topics        │   │
│   │              ▼                                 ▼               │   │
│   │  ┌──────────────────────────────────────────────────────────┐  │   │
│   │  │                        ros-dev                           │  │   │
│   │  │ ──────────────────────────────────────────────────────── │  │   │
│   │  │ • Чистый ROS 2 Humble (алгоритмы, навигация, одометрия)  │  │   │
│   │  │ • Монтирует исходники из локальной папки ./src           │  │   │
│   │  └──────────────────────────────────────────────────────────┘  │   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

1. **`px4-sim`**:
   - Headless-сервер Gazebo Harmonic (`gz sim -s -r`).
   - PX4 SITL автопилот (модель `gz_x500_depth`).
   - `MicroXRCEAgent` для связи автопилота с ROS 2.
2. **`ros-sim-bridge`**:
   - `ros_gz_bridge`: преобразует данные сенсоров и время `/clock` из Gazebo в топики ROS 2.
3. **`ros-dev`**:
   - Рабочее пространство для твоего кода на ROS 2 Humble (монтирует `./src`).
4. **Gazebo GUI (на хосте macOS)**:
   - Легковесный нативный визуализатор, подключающийся к серверу симуляции по сети.

## 🚀 Быстрый запуск

### Требования
1. **OrbStack** (или Docker Desktop) на macOS.
2. Установленная на хосте Gazebo Harmonic:
   ```bash
   brew install gz-harmonic
   ```

---

### Запуск симуляции (в 2 шага)

Все рутинные действия автоматизированы через `Makefile` и скрипт `sim/run_gui.sh`.

#### Шаг 1: Запуск бэкенда симуляции
В первом терминале:
```bash
cd pickme_drone
make sim
```
> **Что происходит:** Поднимаются все контейнеры, стартует Gazebo Server, PX4 SITL и Micro-XRCE-DDS Agent.

#### Шаг 2: Запуск 3D-визуализации
Во втором терминале:
```bash
cd pickme_drone
make gui
```
> **Что происходит:** Скрипт автоматически определит IP контейнера симуляции в OrbStack, синхронизирует 3D-модели (если их нет на хосте) и откроет окно Gazebo с дроном `x500_depth`.

## 🛠 Полезные команды

| Команда | Описание |
|---|---|
| `make sim` | Запустить всю симуляцию в foreground |
| `make gui` | Открыть 3D-интерфейс Gazebo на Mac |
| `make down` | Остановить и удалить все контейнеры |
| `make build` | Пересобрать образы Docker |
| `make logs` | Смотреть логи всех контейнеров в реальном времени |
| `make shell-dev` | Войти в терминал контейнера разработки `ros-dev` |
| `make shell-sim` | Войти в терминал контейнера симулятора `px4-sim` |

---

## 🧑‍💻 Разработка в `ros-dev`

Все твои ROS 2 пакеты создаются и редактируются в папке `./src` на хосте. Они автоматически синхронизируются с `/home/developer/workspace/src` внутри контейнера `ros-dev`.

Чтобы собрать и запустить свои ноды:
```bash
# Входим в контейнер разработки
make shell-dev

# Внутри контейнера:
colcon build
source install/setup.bash
ros2 topic list
```

## ❓ Частые вопросы и Troubleshooting

### Почему 3D-модель дрона не отображается или ругается на `.dae`/`.png`?
3D-меши должны быть доступны локально на хосте. Скрипт `make gui` копирует их автоматически при первом запуске в папку `sim/models`. Если нужно обновить модели вручную:
```bash
docker cp $(docker compose -f compose.sim.yaml ps -q px4-sim):/home/developer/PX4-Autopilot/Tools/simulation/gz/models/. ./sim/models/
```

### Как остановить симуляцию?
Нажми `Ctrl+C` в терминале с `make sim`, либо в отдельном терминале выполни `make down`.
